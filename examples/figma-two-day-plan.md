# 两天内用可展示作品倒逼学会 Figma 产品原型交付

## 目标选择

- 目标岗位或场景：产品助理
- 推荐目标等级：L3｜产品原型交付（推荐目标）
- 推荐理由：产品助理需要能独立搭建中保真原型、表达交互规则并完成分享交付；L4 和 L5 的设计系统与视觉专家能力通常不是这个岗位的速通重点。
- 最终演示：完成发现、收听、播放器、播放列表和返回的完整演示。

## 能力等级

| 等级 | 能力标准 | 用途 |
| --- | --- | --- |
| L1｜查看与协作 | 能查看页面、图层和标注，理解 Frame、约束与组件，导出素材并参与评论。 | 接收设计稿并与设计、研发沟通。（可选） |
| L2｜基础独立操作 | 能独立创建 Frame、文本、形状和基础组件，使用 Auto Layout 组织页面并完成简单连线。 | 多数产品助理岗位的最低可上手要求。（最低可用） |
| L3｜产品原型交付 | 能使用组件、变体、响应式布局、弹窗和页面跳转交付中保真原型，覆盖表单与异常状态，并完成分享或 Dev Mode 交接。 | 足以写“熟练”，能支撑面试作品和日常产品原型沟通。（推荐目标） |
| L4｜设计系统 | 能治理复杂变量、主题模式、组件库和多条件交互插件，并维护团队规范。 | 设计系统维护或设计平台岗位更适用，产品助理通常不需要速通。（通常不需要） |
| L5｜设计专家 | 能建立完整设计系统、品牌视觉体系和复杂高保真交互动效。 | 适合 UI/UX 设计师或设计负责人，不是本次两天目标的合理范围。（通常不需要） |

## 作品范围

- 作品：小宇宙收听管理改版
- 必须包含：6 个主要页面；3 个关键状态；主要任务链路可点击
- 明确不做：完整还原小宇宙品牌视觉；复杂动效参数；插件开发；完整商业产品所有页面
- 时间预算：Day 1 120 分钟；Day 2 150 分钟，合计上限 270 分钟
